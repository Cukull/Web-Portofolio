\# 📋 Product Requirements Document



\## 1. Project Overview



\### Project Name



Personal Portfolio Website



\---



\### Vision



Membangun website portfolio modern yang merepresentasikan kemampuan sebagai developer sekaligus menunjukkan perhatian terhadap desain, performa, pengalaman pengguna, dan kualitas implementasi.



Website bukan hanya tempat menyimpan project, tetapi menjadi representasi profesional yang dapat dipercaya oleh recruiter, client, maupun komunitas.



\---



\### Objectives



Website harus mampu:



\- Menampilkan identitas pribadi secara profesional.

\- Menampilkan project sebagai studi kasus.

\- Menjadi CV online.

\- Mempermudah recruiter menghubungi pemilik website.

\- Menjadi media personal branding.

\- Menjadi tempat eksperimen UI dan animasi modern.



\---



\# 2. Success Metrics



Website dianggap berhasil apabila:



\- Lighthouse Performance ≥ 95

\- SEO ≥ 95

\- Accessibility ≥ 95

\- Best Practices ≥ 95



Pengunjung dapat memahami isi website kurang dari 2 menit.



Project dapat ditemukan maksimal dalam 2 klik.



Website tetap nyaman pada perangkat mobile.
